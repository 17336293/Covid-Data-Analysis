# Covid-Data-Analysis
This was one of my first major projects as a data analyst. I was granted access to a subset of data from the Centers for Disease Control and Prevention (CDC).

Part 1 — Data Cleaning and Preparation
Taking the initial dataset and transforming it into usable data for a machine learning algorithm that attempts to predict the mortality rates of COVID-19.

Part 2 — Model Training and Development
Training a machine learning model on the prepared dataset to predict COVID-19 mortality rates.
